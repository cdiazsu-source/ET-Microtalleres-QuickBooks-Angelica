# Microtaller UIFCE: Contabilidad en la nube con QuickBooks

Infografía del microtaller gratuito y virtual (2 sesiones, válido por horas de corresponsabilidad), con la línea gráfica del Boletín UIFCE.

- `index.html`: visor con botones **Propuesta 1 / 2 / 3 / 4** para navegar entre propuestas.
- `propuesta-1/`: infografía (HTML 1080 px de ancho + PNG exportado).
- `propuesta-2/`: infografía vertical larga (1080 px de ancho) con la plantilla de Microtalleres UIFCE.

Para verla en local, abre `index.html` en el navegador.
- `propuesta-3/`: infografía vertical con la línea gráfica del Simulador de Perfiles UIFCE.
- `propuesta-4/`: infografía vertical con la línea gráfica de los Cursos Libres FCE (fondo azul con cuadrícula y tipografía grande).
